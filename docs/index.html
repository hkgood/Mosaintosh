The machine

4 MB Mac Plus
at 1.00× real time

  • CPUMotorola 68000 via Musashi
  • Display416×416 · 1-bit · 30 Hz update
  • InputCST9220 touch → Mac mouse
  • Storage8 MB HFS + 2 MB PSRAM overlay

Build it

先在 Mac 上验证，再装进设备。

make board
make board-window

python mosaico.py iris system-update \
  --project projects/mosaintosh

ROM 与 System 7.5.3 镜像不在仓库中。请使用你合法拥有的副本。
